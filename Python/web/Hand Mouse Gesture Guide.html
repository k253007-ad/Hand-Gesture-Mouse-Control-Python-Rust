App keys and safety

H

Switch the preferred green pointer hand.

Space

Pause or resume. Releases any drag.

Q Esc

Quit from the camera preview.

↖

Move the physical mouse into a screen corner for the fail-safe stop.

Using one hand? It can move, left click, drag, open Start, open the window picker, and toggle controls. Double click, right click, and scrolling need both hands. If the preferred hand leaves the frame, the visible hand becomes the pointer. The preview's center box maps to the primary display.
